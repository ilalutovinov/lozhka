# 🥗 Лёгкость — меню на неделю по твоему бюджету

Next.js 14 + Supabase (Postgres, Auth, RLS) + Leaflet/OpenStreetMap. Деплой — Vercel.

**Что умеет:** квиз → меню на неделю под диету/аллергии/бюджет/калории → список покупок с ценами →
сравнение магазинов на карте (с учётом дороги) → «каждый товар там, где дешевле» → свои рецепты с авто-КБЖУ →
регистрация и синхронизация → админка (магазины на карте, цены, модерация рецептов, отчёты пользователей о ценах).

Без Supabase приложение тоже работает — в **демо-режиме** на данных из `lib/seed.js` (данные только в браузере).

## Запуск локально
```bash
npm install
cp .env.example .env.local      # заполни ключи (шаг 2 ниже) — или пропусти для демо-режима
npm run dev                     # http://localhost:3000
npm run test:planner            # проверка алгоритма без БД
```

## Подключение базы (Supabase, бесплатно)
1. supabase.com → New project.
2. **SQL Editor** → вставь и выполни весь `supabase/schema.sql`.
3. **Project Settings → API**: скопируй `Project URL`, `anon key`, `service_role key` в `.env.local`.
4. `npm run seed` — зальёт продукты, магазины, цены и 24 рецепта.
5. **Authentication → Providers → Email**: для быстрого теста отключи «Confirm email».
6. Зарегистрируйся на сайте, затем в SQL Editor:
   ```sql
   update profiles set role = 'admin' where email = 'ТВОЯ_ПОЧТА';
   ```
   В меню появится «Админ».

## Рецепты из интернета
`npm run import:meals 60` — тянет рецепты из TheMealDB (бесплатный API), сопоставляет ингредиенты с твоими продуктами,
считает граммовки и КБЖУ, кладёт со статусом **«на модерации»**. Одобряй в Админ → Рецепты.
Ограничения: TheMealDB англоязычный (названия/шаги нужно перевести), берутся только блюда, где ≥60 % ингредиентов сопоставились.
Для русскоязычной базы потом добавь шаг перевода (например, через Claude API) — скрипт легко расширить.

## GitHub + Vercel
```bash
git init && git add . && git commit -m "Лёгкость v1"
git branch -M main
git remote add origin https://github.com/ТЫ/legkost.git
git push -u origin main
```
vercel.com → Add New → Project → выбери репозиторий → в **Environment Variables** добавь
`NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` (service_role в Vercel **не** добавляй) → Deploy.
Затем в Supabase → Authentication → URL Configuration укажи адрес Vercel как Site URL.

## Как считается меню (`lib/planner.js`)
Для каждого слота (день × приём пищи) блюда оцениваются: штраф за повтор и за то же блюдо подряд, цена по ценам магазина,
бонус за общие продукты с уже выбранными (меньше остатков), скорость/одна сковородка, диета (кето/белок), близость к калорийности.
Если сумма выше бюджета — цикл замен: меняем блюдо, где замена даёт максимальную экономию.
Магазин: корзина по каждому магазину + `км × 2 × 15 сом` (константа `TRAVEL_SOM_PER_KM`); отдельно считается «разделённая» корзина.

## ⚠️ Важно
- **Цены и координаты в `lib/seed.js` — демонстрационные.** Реальные внеси в админке; пользователи могут присылать правки (💬 в списке покупок).
- Рецептов в seed всего 24 — для вегетарианцев/безглютеновых меню будет повторяться, пока не импортируешь больше.
