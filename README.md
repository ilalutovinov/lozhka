# 🥄 Ложка

Бесплатный подборщик недельного рациона по бюджету для Кыргызстана: выбираешь базар или супермаркет, бюджет в сомах, ограничения и любимые блюда, а получаешь меню на неделю, стоимость и список покупок с граммовками.

## Запуск
Статический сайт, сборка не нужна. Открой `index.html` или запусти `npx serve`.
Деплой: GitHub → Vercel → Import Project (Framework: Other).

## Структура
- `index.html` — страница
- `style.css` — дизайн (переменные цветов в начале файла)
- `app.js` — шаги, алгоритм подбора (`gen()`), админка (код `admin`, демо)
- `db/schema.sql` — схема Supabase для следующего этапа

## Сейчас работает
Шаги подбора, алгоритм по бюджету, список покупок, демо-вход, админка (блюда, цены, статистика). Всё хранится в браузере (localStorage).

## Дорожная карта
1. Данные: реальные цены базаров и сетей, больше блюд (сейчас цены примерные)
2. Supabase: общая база блюд и цен, админка по роли
3. Вход через Telegram-бота (@BotFather → Login Widget)
4. Свои цены пользователей (с датой, медианой, модерацией)
5. Карта (Leaflet + OpenStreetMap), комментарии
6. Редактирование рациона, замена блюда, калории
7. Кыргызский язык, оплата и ИИ-советы (позже)
